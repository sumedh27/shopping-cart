# Shopping Cart Application

A modern shopping cart web application built to practice real-world frontend architecture — component composition, state management, derived state, and UI performance.

> Designed as a learning project focusing on how real e-commerce carts behave.
> 
## Features

- Product listing UI
- Add / remove items from cart
- Quantity increment & decrement
- Live total price calculation
- Persistent cart state
- Optimized renders (memoization & controlled updates)
- Responsive layout

---

## Getting Started

### 1. Clone the repo
    git clone https://github.com/sumedh27/shopping-cart.git
    cd shopping-cart

### 2. Install dependencies
    npm install

### 3. Run the development server
    npm run dev

App runs on:  
http://localhost:5173
